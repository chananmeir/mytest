📚 How to Create Background Images

Background images are used for game scenes and locations:

  • Interior Locations: living_room, bedroom, kitchen, bathroom, office
  • Exterior Locations: outdoors, street, park, backyard
  • Public Places: restaurant, mall, cafe, gym
  • Time Variants: Add _day, _night, _evening suffixes (e.g., living_room_day, living_room_night)

AI Image Generation Tips:

  • Recommended size: 1920x1080 pixels (landscape orientation)
  • Use wide-angle perspective for interior rooms
  • Ensure consistent lighting and art style across all locations
  • Example prompt: "Wide-angle view of modern living room, daytime, natural lighting, cozy furniture, realistic style, 1920x1080"

💡 Tip: Create time-of-day variants (day/night/evening) for indoor locations to add realism. Keep backgrounds uncluttered so character sprites stand out!

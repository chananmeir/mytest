📚 Asset Production Quick Reference

Quick tips for creating game assets:

Character Images
  • Size: 1024x1536px (portrait)
  • Format: PNG with transparency
  • Include base body + expressions
Backgrounds
  • Size: 1920x1080px (landscape)
  • Format: JPG or PNG
  • Create day/night variants
UI Elements
  • Size: 32x32 to 256x256px
  • Format: PNG with transparency
  • Keep simple and clear
General Tips
  • Maintain consistent art style
  • Use AI tools (DALL-E, Midjourney)
  • Name files descriptively

💡 Pro Tip: Organize files locally first, then use bulk upload to save time. See CHARACTER_GRAPHICS_GUIDE.md and TEMPLATE_IMAGES_GUIDE.md for detailed instructions!

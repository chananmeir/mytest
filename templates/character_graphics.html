📚 How to Create Character Images

Character images should include:

  • Base Bodies: Full body images in base/ folder
  • Expressions: Facial expressions in expressions/ folder (neutral, happy, sad, angry, surprised, aroused, embarrassed, confused, confident)
  • Outfits: Different clothing variations in outfits/ folder
  • Portraits: Close-up character portraits in portraits/ folder

AI Image Generation Tips:

  • Use consistent style across all images for the same character
  • Recommended size: 1024x1536 pixels (portrait orientation)
  • Use PNG format with transparent background when possible
  • Example prompt: "Full body portrait of [character description], standing straight, neutral expression, front view, realistic style, PNG transparent background, 1024x1536"

💡 Tip: Create character-specific images in characters/[Name]/ folders. Shared clothing should go in shared_clothing/ to avoid duplication! See CHARACTER_GRAPHICS_GUIDE.md for full details.

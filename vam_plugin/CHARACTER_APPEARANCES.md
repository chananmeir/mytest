# Character Appearance Guide for Virt-A-Mate

This guide specifies how to create each character in Virt-A-Mate to match the game descriptions.

## Character Setup Checklist

For each character:
1. Create Person atom with character name (e.g., "Ruth", "Tom")
2. Set age-appropriate skin texture
3. Configure body morphs (height, weight, proportions)
4. Set facial features
5. Add hair (style and color)
6. Create default outfit
7. Save as appearance preset
8. Tag as "FamilyDynamicsRPG"

## Technical Notes

### Saving Characters

1. After creating each character, save as:
   - Appearance preset: `[Name]_Default.vap`
   - Clothing preset: `[Name]_Outfit_[Description].vac`
   - Morph presets: `[Name]_[Expression].vam`

2. Tag all with: `FamilyDynamicsRPG`

### Animation States

Create idle animations for each character:
- Neutral standing
- Sitting on couch
- Walking
- Talking (gesturing)
- Thinking (hand on chin)
- Using phone
- Drinking coffee

### Location Positions

Set up spawn points in each scene for where characters should appear based on schedules.

### Expression Transitions

Enable smooth transitions between expressions (1-2 seconds) for natural emotion changes.
